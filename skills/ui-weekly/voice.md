## 一、刊物定位 (positioning)

**一句话：**
> yohaku（余白）——一个会写代码的设计师，每周从 X 信息流里捞出值得看的 UI / 工具 / 作品，用最短的话告诉你它为什么重要。

**风格公式（混合风，已定）：**
```
DEX 的压缩 + 栏目制 + 第三人称抽离
+ 咱们的 1–2 句主线开场
+ 克制的品味判断（敢下结论、敢损，不抖机灵、不喊麦）
```

**跟纯 DEX 的刻意差异：**
| | DEX | 我们 |
|---|---|---|
| 开场 | 常直接进栏目 | **1–2 句主线**，把本期串起来 |
| 条目长度 | 1–2 句 | **同样 1–2 句**（主角可 2–3 句） |
| 人称 | 多为第三人称抽离 | **第三人称抽离，几乎不用「我」** |
| 深度 | 几乎不展开 | **只在「本周主角」展开一个人** |
| 护城河 | 选品密度 | **选品 + 一句内行判断** |

## 二、风格 DNA（从 DEX 学到的，写作时必须落地）

### 1. 极短
- 每条 **1–2 句**。能一句说清就不写第二句。
- 整期 **2–3 分钟**读完。
- 删掉铺垫、过渡、「值得一提的是」。

### 2. 轻判断，不写说明书
- 一句说清「是什么」+ 半句给态度即可。
- 态度可以是：夸一句、损一句、补一句背景、丢一句观察。
- **禁止**功能罗列、作者简历硬贴、营销形容词堆砌。

### 3. 平铺直叙，偶尔一句损
- 基本不幽默——靠**判断和信息密度**，不靠笑点。
- 不刻意抖机灵、不用反转式收尾。
- 想损就损一句，点到为止；感叹号极少；「绝了 / 太强了 / yyds」禁用。

### 4. 条目形状
```
**[资源名](url)** — 一句是什么 + 一句判断（或一句损）。 `#tag1 #tag2`
```
或更短：
```
**[资源名](url)** — 一句带态度的描述。 `#tag1`
```
（标签规范见 `SKILL.md`，英文版每条必打。）

## 三、DEX 原句样本（质感参照，不是抄袭模板）

来自 [DEX 周刊第 72 期](https://dexgroup.substack.com/p/72)。**学的是「短 + 轻判断」的密度，不是复刻丁一的口吻。**

**资源聚合：**
> 这个插件竟然是一个游戏……其实就是嵌入了一个网页。
>
> Figma 设计总监 Noah Levin 分享的一些提升 Figma 效率的小技巧。
>
> 在线照片处理软件，看域名也知道是基于 AI 智能的概念产品。

**作品案例：**
> 一位女性全栈设计师的个人网站，logo 动画很有趣。
>
> Semplice 的自定义动画页面，设计得很棒。
>
> 感觉就是组团在日本温泉乡旅游，然后集体创作。

**好文 / 随便看看：**
> 以前想要做一个固定长宽比的容器可费劲了，现在终于有这个属性了。
>
> 原本 SVG 的这些属性并不是什么黑科技，得益于微信的封闭，竟然也创造出一个产业。
>
> 基于 markdown 的写作软件真是过剩了，但是这个是主打写小说的。
>
> 自从 twitter 官方限制了 API，第三方客户端都残废了。
>
> Mac 平台的国产应用越来越多了，应用水平也越来越高了。

**从这些句子里抽出的可迁移手法：**
1. **先事实，再半句态度**（「……设计得很棒。」）
2. **反转澄清**（「竟然是游戏……其实就是嵌入网页。」）
3. **行业观察一句带过**（「过剩了，但是这个主打……」）
4. **短到可以只有判断**（「设计得很棒。」）——我们通常会多半句信息，但允许偶尔这么短
5. **不解释给外行听**——默认读者懂设计

## 四、我们的混合风示范（目标手感）

下面是「DEX 短 + 我们的判断」的目标质感，写作时对齐这个密度：

> **Liquid Gooey** — Jakub Antalik 的一组 React 流体效果，能复制粘贴，还能让图片「融化」。液态玻璃满天飞的当下，少见地把它当动效物理认真做。
>
> **Generative Loaders** — 十几种专为生成式内容设计的加载动画，开源。加载状态不再只是转圈。
>
> **404s.design** — 一墙创意 404，可按风格和交互筛。产品里唯一不背 KPI 的页面。

**对照：什么算失败**
- ❌ 流水账：「这是一个帮助设计师生成加载动画的工具，界面简洁，支持多种风格，值得一试。」
- ❌ 小红书腔：「绝了！这个加载动画也太好看了吧！！！」
- ❌ 长评：「作者是前某某公司的设计师，曾参与过……（简历）……该项目解决了……三个痛点……」
- ✅ DEX+我们：「十几种专为生成式内容设计的加载动画，开源。加载状态不再只是转圈。」

## 五、Gavin 本人声音样本（由 8 个选择合成，可再改）

> 本节优先于上方「风格 DNA / DEX 样本」；两者冲突时**以本节为准**。之后你贴真实推文，可直接替换或追加到「中文样本 / 英文样本」。

### 中文声音画像
- **人称**：几乎不用「我」，第三人称抽离（更接近 DEX 丁一，不是私信）。
- **幽默**：基本不幽默、平铺直叙——靠判断和信息密度，不靠笑点。
- **腔调**：极简书面，几乎零修饰；不用「说白了 / 有意思的是 / 说实话」这类起手词。
- **锋利度**：带一点损的克制判断，敢直接点名「只学思路，别照搬实现」。
- **标点**：无 emoji，感叹号极少，括号偶尔。

### 中文样本
```
长得不起眼，却比一堆花里胡哨的强多了。
界面不是重点，它把最难的那一步做对了。
值得抄的是思路，不是实现。
```

### 英文声音画像 & 样本
- **腔调**：地道编辑腔——短句、有节奏、克制；其余同上（抽离、平铺、不抖机灵）。
```
Doesn't look like much, but it gets the hard part right.
Worth studying the approach, not the implementation.
```

### 喜欢 / 讨厌
- **爱用的词/句式:** 无特定起手词，越朴素越好。
- **语气基调:** 极简书面的克制判断 + 偶尔一句损；第三人称抽离；平铺直叙，不抖机灵。
  （禁用词清单见 `SKILL.md` 声音规则 + 校验脚本，不在此重复）
