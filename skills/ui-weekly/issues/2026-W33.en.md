## Intro

Three galleries, one job: doing the filtering for the reader. Curation used to be a blog post; now it's the product.

## Resources

**[Uiverse](https://uiverse.io/)** — open-source UI elements, community-made, copy the HTML/CSS and go. Design systems keep getting heavier; this one ships a single element instead. `#components #css #opensource`

**[Dark Design](https://www.dark.design/)** — hand-picked dark websites, one vertical, no noise. Dark mode has moved from a feature toggle to an aesthetic worth its own site. `#inspiration #darkmode`

**[60fps](https://60fps.design/)** — interaction details from well-built iOS and web apps, filtered by frame rate. The name is the filter: nothing below 60fps. `#motion #inspiration`

## Sign-off

All three get the same thing right: curation as a product.
