## Intro

Screens are mostly text. Which makes it odd how rarely the text gets the design budget.

## Resources

**[Google Fonts](https://fonts.google.com/)** — the default starting point, and the reason half the web looks the same. The variable font support is quietly the best feature. `#fonts #typography #web`

**[Fontsource](https://fontsource.org/)** — self-host any Google Font in a few lines. The answer when you care about performance or live somewhere Google's CDN doesn't. `#fonts #selfhosting #web`
![Fontsource](assets/2026-W36/fontsource.webp)

**[Practical Typography](https://practicaltypography.com/)** — the shortest real book on type, free, and it reads like a person arguing with you. `#typography #books #writing`

## Work

**[Monospace](https://monospace.land/)** — a site that collects monospace typefaces and nothing else. One constraint, done thoroughly. `#typography #inspiration #monospace`
![Monospace](assets/2026-W36/monospace.webp)

## Sign-off

Get the type right and the rest has room to be wrong.
