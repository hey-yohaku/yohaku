# yohaku 设计规范

> 余白 —— 一份把策展当手艺的周刊。网站的设计语言：**书卷索引 × 编辑排版 × 暖纸**。
> 遵循的 Meng To skills：`book-serif-index`、`editorial-tech`、`editorial-portfolio-chapters`、`clean-minimal-beige-light-mode`（见 `agent-skills/web-design/`）。

## 1. 定位

- 界面应当像一份**有索引的杂志 / 档案阅读器**，而不是博客列表或 SaaS 仪表盘。
- 关键词：克制、密度、品位、留白。少即是多，但"少"不等于空——每条都要有判断。
- 动效安静、文学化：掩罩文字揭示、轻缓入场、克制 hover，不弹跳、不炫技、不劫持滚动。

## 2. 字体系统（三层，各司其职）

| 层 | 用途 | 字体栈 |
|---|---|---|
| 衬线 `serif` | 标题、期号大标题、hero | Newsreader, Fraunces, Georgia, Songti SC, SimSun |
| 无衬线 `sans` | 正文、点评、导航 | system-ui, PingFang SC, Hiragino Sans GB, Microsoft YaHei |
| 等宽 `mono` | 元数据：期号、日期、栏目名、标签、页码、URL 域名 | ui-monospace, SF Mono, JetBrains Mono, Menlo |

- **mono 是"技术标注"层**：所有元数据（`2026-W33 · 2026-08-13`、`资源`、`#components`、`page 01`）用 mono 小字 + 宽松 tracking + 低对比色。
- 衬线标题是"书卷"层，正文无衬线是"可读"层，mono 是"索引"层。三层不可混用。

## 3. 表面与颜色（Flexoki 纸墨 + 朱红印章）

- **背景**：暖纸 `#FFFCF0`（亮）/ 墨 `#100F0F`（暗）。不是冷白，不是纯黑。
- **层次**：用低对比 hairline 边框（`#E6E4D9` / 暗 `#282726`）和暖色阶分层，不用重阴影、不用玻璃拟态。
- **强调色**：朱红 `#AF3029`（亮）/ `#D14D41`（暗）——牛血红/印章色。
  - **只做信号色**：hover、激活态、栏目标记、页码、焦点。**绝不铺满**，绝不用它做大面积背景。
  - 一个页面里朱红出现的位置应当数得过来。
- 纸张质感：轻微、当代，不做旧、不脏、不骷髅拟态。

## 4. 布局（编辑排版 + 索引导航）

- **网格**：桌面 12 列，页边距 40–64px；内容主列 `max-w-3xl`（~48rem）居中，如杂志正文栏。
- **不对称优先**：大标题 + 安静元数据并置，避免居中 SaaS hero。留白是节奏的一部分。
- **索引导航**（书卷感）：
  - 首页 = 目录：期号（mono）+ 标题（衬线）+ 日期（mono）+ 摘要，hover 朱红。
  - 单期页 = 章节：按**栏目**（资源/工具/作品/值得一读…）分组，栏目名用 mono + 朱红标记。
- **细线**：条目左侧 2px 细线、栏目间 hairline 分隔，替代卡片和阴影。
- **圆角**：外壳可微圆（4–8px），内部结构保持锐利。
- **元数据常显**：标题、链接、日期不藏在 hover 后；hover 只做颜色/下划线提示。

## 5. 动效默认值（editorial-portfolio-chapters）

- 控制反馈：**160–220ms**；章节/页面入场：**500–760ms**。
- 子元素 stagger：**45–70ms**，缓动 `cubic-bezier(.22,.61,.36,1)`。
- 入场用 masked reveal / fade-up；hover 只用颜色或下划线，不位移、不缩放超过 `1.02`。
- 尊重 `prefers-reduced-motion`；不劫持滚动；路由切换时清理 timeline。

## 6. 双向一致性

- EN 衬线标题 ↔ CN 宋体标题；mono 元数据两版通用（期号/日期是语言无关的）。
- 中文标点、行高（`leading-relaxed` 起）在 CN 下更宽松。
- 标签（tags）**只在检索 JSON 里存在，页面上不显示**；页面分组用栏目（section）。

## 7. 禁令

- 不要冷白 SaaS、不要重阴影、不要玻璃拟态、不要彩虹多色、不要弹跳动效。
- 不要把朱红当主色铺满；不要把每条都做成 hero。
- 不要"扁平奶油卡片 + 衬线字"——要有真实的索引结构、mono 元数据和纸张层次。
